# Onde ficam as regras deste projeto

Este arquivo existe só para apontar. O conteúdo está em outro lugar.

- **`FORMA-DE-TRABALHO.md`** — como se trabalha neste repositório: stack, arquitetura, convenções de código, regras de git, fluxo de entrega. **Leia antes de qualquer tarefa.**
- **`docs/GDD.md`** — o Documento de Design do Jogo: mecânicas, indicadores, regiões, árvore de habilidades, eventos, contratos de dados e balanceamento. **Leia antes de qualquer tarefa.**
- **`PLANO.md`** — o backlog, com uma tarefa por vez.
- **`PROGRESSO.md`** — o diário datado; atualize ao final de cada tarefa.

Em caso de conflito entre uma instrução do chat e esses arquivos, avise e peça confirmação antes de prosseguir.
